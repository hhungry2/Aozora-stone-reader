## 2026年10月9日: 初期実装と外字の修正

### 青空文庫リーダーの初期実装

対応コミット: `eb92f897`

- 20作品、本文613,774文字を同梱し、本棚・検索・読書画面を実装した。
- 縦書き・横書きともStoneを通して本文を組版し、アプリ側でルビ・傍点・外字画像を追加描画した。
- ページ送り、目次、しおり、表示設定、読書位置の保存・復元を実装した。
- 保存位置はページ番号ではなく、作品ID・内容版・ブロックID・ブロック内のUTF-16位置を使う方式にした。
- 公式CSVとXHTMLから作品を取り込む処理、出典・底本・入力者・校正者などの保持、GitHub Pages向けの構成を整えた。

### 外字のUnicode化と位置の互換性

対応コミット: `4ebf4abf`

- 『蜘蛛の糸』の外字画像「犍」が後続文字と重なる問題に対処した。
- JIS X 0213:2004の面区点を確定できる外字はUnicodeへ変換し、本文のフォントで表示するようにした。
- 当時の20作品で35種類・88箇所を変換し、元画像・注記・変換文字・位置の対応記録を保持した。
- 補助漢字や結合文字列によってUTF-16長が変わる場合も、既存の読書位置・しおりを補正して復元する処理を追加した。

## 2026年10月11日: CSSによる比較表示モード

依頼: このリーダーをstone-engine.jsのテスト用途として使い、ライブラリを使わない場合の表示と比較できるようにする。

この追加変更は、後続のサイト名表示の調整とあわせて公開する。

- 設定の先頭に「表示エンジン」を追加し、「Stone（stone-engine.js）」と「CSS（ライブラリ未使用）」を切り替えられるようにした。
- 初期値はStoneとし、既存の保存設定を維持した。モードの選択もブラウザ内に保存する。
- CSSモードでは、標準のHTMLと`writing-mode: vertical-rl` / `horizontal-tb`で本文を配置する。ルビは`ruby` / `rt`、傍点はCSS、外字・図版は画像で表示する。
- Stoneの組版・Canvas計測・SVG描画・コピー処理・先読みを経由しない構成にした。Stone関連のコードは遅延読み込みにし、CSSモードで再訪した場合もStone本体を取得しない。
- 本文を連続配置し、ページ送りは1行分を重ねた画面単位の移動とした。画面の端で切れた文字も次の画面で読めるようにする。選択・コピーとタッチ操作はブラウザの標準動作を使う。
- 読書位置・目次・しおりは既存の本文アンカーを共有し、DOMの文字位置へ対応させる。フォントや画面領域の変更後も位置を復元する。
- CSSモードでは1画面表示とし、見開き・先読み・約物の幅・行の寄せ・文字枠などStone専用の設定を無効化する。選択値は保持し、Stoneへ戻した際に再利用する。
- 同じ本文でもページ境界は一致するとは限らない。本文全体をHTMLに配置するため、長編ではDOMとブラウザの配置処理が増える。

実装時の確認では、単体テスト242件、既存StoneモードのE2E42件（PC・モバイル）、本番ビルドが成功した。ビルドしたファイルでも、CSSで開始した際のStone関連チャンク取得が0件で、Stoneへ切り替えた時点で初めて取得されることを確認した。

CSSモードの新規E2Eは5シナリオ×4構成の20ケースを確認した。対象はChromiumのPC・モバイル、Firefox、WebKitモバイル相当。ライブラリの未取得、原文との一致、ルビ・傍点・画像、切り替え時の位置保持、目次・しおり・再訪、320px幅、設定変更後の復元、横書きのキーボード操作、ページ端の文字が次画面で完全に見えることを含む。最終的なページ送り修正後は、その変更が影響する8ケースを再実行して成功した。

## 継続事項と対応範囲

- 公式CSVの更新後は取り込みを再実行する。本文を同梱できない8作品の例外も、その際に再試行する。
- 複雑なルビの割り付けや、地付き・囲み・添字などの版面再現には簡略化がある。変更内容と原注記は保持する。
- しおり・読書位置・表示設定はブラウザ内の保存であり、端末間同期には対応していない。
- 検索は書誌情報を対象とする。本文全体の検索、任意URL/ローカルファイルの取り込み、PWA・オフライン読書の保証は実装範囲に含めていない。
- ブラウザ自動化のモバイル相当表示と、iOS/Android実機の確認は区別する。読み上げ・実機性能などの継続事項は[初版の記録](implementation-notes.md#初版の制約と未実施の確認)に残している。
